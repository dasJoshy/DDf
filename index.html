❓ Häufig gestellte Fragen

Brauche ich einen Server zum Testen? ›
Nein! Öffne `duemmste_fliegt_ui.html` einfach im Browser. Das Prototype ist vollständig standalone und funktioniert offline. Für die echte Anwendung brauchst du dann Backend + WebSocket.
Kann ich das in Figma importieren? ›
Ja! Nutze `FIGMA_SETUP.md` als Guide. Es gibt zwei Optionen: (1) Manueller Aufbau von Grund auf, oder (2) Export aus HTML + Screenshot-Import. Die Anleitung ist sehr detailliert.
Welche Browser werden unterstützt? ›
Chrome, Firefox, Safari, Edge (alle modernen Versionen). Auch auf Mobile Browsern (iOS Safari, Chrome Mobile). Das UI ist voll responsive und funktioniert überall.
Kann ich den Code anpassen / branchen? ›
Absolut! Der Code ist vollständig dokumentiert und modular. Alle CSS-Variablen sind zentral definiert, sodass du Farben/Spacing leicht anpassen kannst. JavaScript ist minimal und einfach erweiterbar.
Wie integriere ich ein Backend? ›
Siehe `DESIGN_SPEC.md` Sektion "Implementation Notes". Das UI ist vom Backend unabhängig. Du ersetzt einfach die Mock-Daten durch API-Calls (POST `/api/game/answer`, WebSocket `/api/updates`, etc.).
Kann ich das Farbschema ändern? ›
Ja, super einfach! Alle Farben sind als CSS-Variablen definiert (`:root { --primary: #6366f1; }` etc.). Ändere die Hex-Werte, und das ganze UI aktualisiert sich automatisch.
